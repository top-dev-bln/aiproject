Cum se instalează și folosește
Pasul 1 — instalare hook (o singură dată):

python install_hooks.py
Pasul 2 — setezi endpoint-ul Qwen (de pe Colab, după ce antrenezi modelul):

# Linux/Mac
export ARCH_MODEL_ENDPOINT=https://your-ngrok-url/generate

# Windows PowerShell
$env:ARCH_MODEL_ENDPOINT = "https://your-ngrok-url/generate"
Pasul 3 — git push normal:

git push
# Hook rulează automat:
# [arch-hook] 12 fisiere Java modificate — analiza statica...
# [arch-hook] Clase: 47, Relatii: 23
# [arch-hook] Mermaid static salvat: docs/architecture/main_20260602_010000.mmd
# [arch-hook] Mermaid LLM salvat:   docs/architecture/main_20260602_010000_llm.mmd
Cum se integrează modelul Qwen antrenat
Format request (ce trimite hook-ul):

POST https://your-endpoint/generate
{
  "prompt": "Generate a Mermaid architecture diagram for the following system:\n\nJava application with 5 classes. services: UserService, ...",
  "max_tokens": 1024,
  "format": "mermaid"
}
Format response așteptat (orice dintre):

{ "generated_text": "classDiagram\n    class UserService ..." }
{ "text": "classDiagram ..." }
{ "mermaid": "classDiagram ..." }
Pe Colab, wrapper-ul de serving trebuie să fie ceva de genul:

@app.route("/generate", methods=["POST"])
def generate():
    data = request.json
    output = model.generate(data["prompt"], max_tokens=data["max_tokens"])
    return {"generated_text": output}
Prioritatea backend-urilor în model_backend.py
Prioritate	Backend	Condiție
1	Qwen2.5-7B fine-tuned	ARCH_MODEL_ENDPOINT setat
2	diagram_generator FastAPI	rulează pe :8000
3	Ollama local	rulează pe :11434
fallback	static only	niciun backend disponibil
Hook-ul nu blochează niciodată push-ul — dacă analiza eșuează, continuă cu exit 0.
