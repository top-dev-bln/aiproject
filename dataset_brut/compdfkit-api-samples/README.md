# ComPDF API Samples

As part of the KDAN ecosystem, [ComPDF](https://www.compdf.com/?utm_source=github&utm_medium=compdfkit-api-samples&utm_campaign=compdfkit_api_samples_repo&ref_platform_id=github_compdfkit) provides powerful PDF APIs for document conversion, parsing, OCR, compression, watermarking, and workflow automation.

[ComPDF API Samples](https://github.com/ComPDFKit/compdfkit-api-samples) provides runnable examples that show how to authenticate, create tasks, upload files, and retrieve results across common ComPDF API workflows.

If you find these samples helpful, please consider giving us a ⭐ **Star** on GitHub! Have feedback or questions? Join the conversation in our [Discussions](https://github.com/orgs/ComPDFKit/discussions).

**Why ComPDF API Samples?**

* **Faster onboarding** — Start from working examples instead of building request flows from scratch.
* **Broad API coverage** — Explore conversion, extraction, OCR, watermarking, and document-processing workflows.
* **Reusable request patterns** — Reuse authentication, task creation, upload, and result retrieval logic in your own tools.
* **Docs-aligned examples** — Cross-check each sample with the official API reference and guides.

## Getting Started

This GitHub repository provides public access to code examples that demonstrate how to programmatically submit requests to the [ComPDF API](https://api.compdf.com/?utm_source=github&utm_medium=compdfkit-api-samples&utm_campaign=compdfkit_api_samples_repo&ref_platform_id=github_compdfkit) service.

Before you begin, you may need to do some preparatory work.

* [Register](https://api.compdf.com/signup?utm_source=github&utm_medium=compdfkit-api-samples&utm_campaign=compdfkit_api_samples_repo&ref_platform_id=github_compdfkit) a free ComPDF API account using email only.
* Obtain the project ID and its related key from the [API Keys](https://api-dashboard.compdf.com/api/keys?utm_source=github&utm_medium=compdfkit-api-samples&utm_campaign=compdfkit_api_samples_repo&ref_platform_id=github_compdfkit) section of the console.
* To start requesting the ComPDF API, please read the comprehensive [API reference](https://api.compdf.com/api-reference/overview?utm_source=github&utm_medium=compdfkit-api-samples&utm_campaign=compdfkit_api_samples_repo&ref_platform_id=github_compdfkit) for the function you need to call.

## Authentication

You can get **accessToken** and related verification information by sending your **publicKey** and **SecretKey** . AccessToken will expire after **12** hours. **When calling the subsequent interface, you must carry this token in the request header**: `Authorization: Bearer {accessToken}`.

Before running each sample program, look for a comment that reads:

> `public_key_******`
> 
> ` secret_key_******`

and replace `******` with your API Keys.

## Workflow

### Create Task

A task ID is automatically generated for you based on the type of PDF tool you choose. You can provide the callback notification URL. After the task processing is completed, we will notify you of the task result through the callback interface. You can perform other operations according to the task result, such as downloading the result file.

### Upload Files

Upload the original file and bind the file to the task ID. The field **parameter** is used to pass the JSON string to set the processing parameters for the file. Each file will generate automatically a unique **filekey**.

Please note that a maximum of five files can be uploaded for a task ID and no files can be uploaded for that task after it has started.

### Execute Task and Get Task Information

After the file is uploaded, the file processing starts and the download link of the corresponding result file is obtained according to the **filekey** of each file
